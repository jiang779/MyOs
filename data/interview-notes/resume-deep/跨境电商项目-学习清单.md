## 一、业务：简历上要讲的 3 个模块

### ① 税率维护

**必记**
- 四维键：国家/地区 × HS 编码 × 方向（进/出口）× 生效日期
- 三类税率：关税 / 增值税 / 消费税；库里存小数（0.13），页面显示 13%
- HS 2/4/6/8/10 位：前 6 位国际通用，后面各国自加 → **按前缀降位匹配**
- 数据量 144 条；澳大利亚 5%/10%/0%（GST 10%、服装关税 5%），文莱 0/0/0

**代码**：`src/views/taxRate/index.vue`（141 行）、`TaxRate.api.ts`、`src/api/home/taxCalc.api.ts`

**验收**
1. 同一国家同一 HS 配了多个长度，为什么？（前缀降位匹配）
2. 页面 13%，库里存什么？
3. 用哪条税率由什么决定？（生效日期）

### ② 税费计算（门户，免登录 `/customs-tax-calc`）

**必记**
- 输入：HS、货值、币种、运费、保险（各带币种）、原产国、目的国、贸易条款、方向
- 完税价格 ≈ 货值 + 运费 + 保险（CIF 口径）
- 三税拆分；返回 `matchMode`（命中级别）、`rateId` + `rateEffectiveDate`（可追溯）
- `preview` 不落库 / `save` 才落库；列表用 `insuranceFee`，详情用 `insurance`
- 导出 Excel / PDF；`disclaimer` 声明非海关认定值

**代码**：`src/views/home/customs/taxCalc.vue` → `components/TaxCalcTrial.vue`、`src/api/home/taxCalc.api.ts`

**验收**
1. 为什么试算和保存要分开？
2. 怎么知道这次用的是哪条税率？
3. 试算 10 次、保存 1 次，库里几条记录？

### ③ 服务商入驻两级审核

**必记**
- 状态机：`pending_level1 → pending_level2 → approved / rejected`
- 四个接口：`approveLevel1/2`、`rejectLevel1/2`，**用 level 参数，不是四套逻辑**
- `profileId` 必须走 query（api 里注释说明踩过坑）
- 动机：一级审资质完整性，二级审合规风控

**代码**：`src/views/serviceProvider/index.vue`（134 行）

**验收**
1. 一级过、二级驳回，最终什么状态？能否重提？
2. 为什么用 level 参数而不是四个接口？
3. 审批按钮由什么控制显隐？（状态 + 权限码）

## 四、被追问时的一句话答案

| 问 | 答 |
|---|---|
| 流式怎么实现 | `ReadableStream` + `TextDecoder` 分片，按 `\n\n` 与 `data:` 切事件 |
| 有什么坑 | 分片切断多字节字符（要 `stream: true`）；现有实现用 `endsWith('}')` 判完整，内容含 `}` 会误判 |
| 断线怎么办 | `requestId` 存 localStorage，走 `GET /airag/chat/receive/{id}` 续收 |
| MCP 和 function calling 区别 | MCP 是工具接入协议，function calling 是模型能力 |
| 知识库前端做什么 | 绑定关系 + 引用展示；切片召回在后端 |
| 税率怎么匹配 | 四维键 + HS 前缀降位，`matchMode` 记录命中级别 |
