# Vue 报错自解释 Agent

## 一句话

粘贴一段 Vue 报错堆栈，返回：这句话在说什么 / 为什么会这样 / 改哪里。

## 为什么做

团队里新人 80% 的时间花在「读不懂报错」上，而不是写代码上。这是一个能被量化的痛点。

## 能讲啥

- 用 Tool Calling 把「查错误码库」做成一个工具，而不是把所有错误码塞进 Prompt
- 报错文本的归一化：同一类报错有十几种写法，先聚簇再匹配
- 结构化输出 + 校验：返回的修复建议必须是可解析的 diff 片段

## 缺啥

- 错误码覆盖率（当前 40% → 目标 85%）
- 没有评测集，改 Prompt 全靠手感 → 第 21 周补
- 只支持 Vue 3，Vue 2 的报错映射是空的

## 架构

```text
错误堆栈 → 归一化 → 特征提取（错误码 / 组件 / API）
   → 工具：查本地错误码库
   → 命中？直接给结果
   → 未命中？交给模型推理并回写库（自增长）
```
