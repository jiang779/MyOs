# 文档问答 RAG 引擎

## 一句话

把散落的 md / pdf 变成能追问的知识库，回答必须带引用，查不到就说查不到。

## 能讲啥

- 两段式检索：关键词 + 向量混合召回，再重排，top-3 准确率提升可量化
- 分块策略对比实验：定长 / 按标题 / 语义分块在同一份文档上的召回差异
- 拒答机制：检索不到就直接说不知道，不做「看起来很合理」的编造

## 缺啥

- 评测集只有 20 问，样本太少，指标波动大
- 中文长文档（>10 万字）场景下分块会切断语义单元
- 没有增量更新，文档改了要全量重建索引

## 架构

```text
文档 → 结构识别 → 语义分块 → 嵌入 → 向量库 + 倒排索引
查询 → 双路召回 → RRF 融合 top-30 → 重排 → top-5 → 生成（带引用）
```
