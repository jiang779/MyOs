# 短视频脚本生成器

## 一句话

把「我今天学到的技术点」变成一条能发出去的 60 秒视频脚本。

## 为什么做

创作这条线最大的阻力不是录制，是「不知道开头第一句说什么」。把开头写出来，剩下的都顺了。

## 能讲啥

- 结构化输出：钩子 / 正文三点 / 结尾引导，用 schema 强约束
- Few-shot 用自己已发布的爆款稿做示例，而不是网上找的通用模板
- 把「我踩过的坑」作为输入而不是「知识点」，天然带个人视角

## 缺啥

- 怎么评价一条稿子好不好？需要先从自己历史视频里提炼评分维度
- 没有素材库，配图还得手动找

## 架构

```text
输入：技术点 + 我的真实经历
  → 检索我的历史爆款稿（Few-shot）
  → 生成三版钩子 → 人选一版
  → 展开成完整口播稿 + 分镜提示
```
