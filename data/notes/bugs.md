# 踩坑本

> 只记「当时卡了超过 20 分钟」的事。20 分钟以内自己就解决了，不值得记。

## 2026-10-07 · 分块时全半角标点混用，句子被切错位

tags: #RAG #文本处理

中文文本里 `。` 和 `.` 混在一起，我用正则按句号切分，结果英文句点先命中，把 `Vue 3.5` 这种版本号也切断了。

排查花了很久，因为切出来的句子「看起来也还行」，只有检索结果不对才暴露出来。

**解法**：切分前统一标点，并且给版本号、URL、代码路径加保护规则，先打标再切。

## 2026-10-06 · 加了 BM25 之后接口慢了 400ms

tags: #性能 #检索

只做向量检索时 P95 是 320ms，接上 BM25 之后变成 720ms。第一反应是 BM25 太慢，实际是两路检索串行执行。

**解法**：改成并行，再用 RRF 融合。降到 380ms。并行之前先别急着换算法。

## 2026-10-04 · localStorage 存了对象，读出来变成字符串

tags: #前端 #localStorage

`localStorage.setItem('state', someObject)` 不报错，读出来是 `[object Object]`，JSON.parse 直接抛异常，整个应用白屏。

而且我在 try/catch 里静默吞了异常，所以连报错都看不到 —— 这才是真正的问题。

**解法**：写入统一 `JSON.stringify`，读取统一走一个带默认值的工厂函数；catch 里至少 `console.warn` 一次。

## 2026-10-02 · 让模型输出 JSON，它在前面加了「好的，这是结果：」

tags: #Prompt #结构化输出

即使明确要求「只输出 JSON」，模型偶尔还是会加一句客套话，`JSON.parse` 就炸。

**解法**：不要试图用 Prompt 100% 消除，改用「宽松解析 + 校验 + 失败重试」。从第一个 `{` 到最后一个 `}` 截出来再解析，失败就把错误信息回传给模型让它自己修。

## 2026-09-28 · 工具调用的循环没有退出条件，跑飞了 60 多轮

tags: #Agent #工具调用

手写 tool loop 时只判断了「有没有 tool_calls」，没设步数上限。模型调一次工具没拿到想要的结果，就换个参数再调，一直调。

账单和我的耐心一起见底。

**解法**：两个退出条件 —— 步数上限（我设 8）+ 连续两次工具结果完全相同时强制终止。

## 2026-09-22 · API Key 写进代码提交到 GitHub

tags: #安全 #工程化

GitHub 的密钥扫描机器人发了警告邮件。删除文件没用，提交历史里还在。

**解法**：立刻吊销重发密钥；把密钥挪到 `.env.local` 并加进 `.gitignore`；再加一个 pre-commit 钩子做正则扫描。上面三件一起做才算解决。
