# 学习笔记 · 放文件规则

**把 `.md` 文件放进对应周的文件夹即可，文件名就是笔记标题，内容没有任何格式要求。**

```
data/notes/
├── week-01/          ← 第 1 周的笔记放这里
│   └── 2026-10-12-虚拟环境踩坑.md
├── week-12/          ← 第 12 周的笔记放这里
│   └── FastAPI 依赖注入.md
└── week-36/
```

## 规则

| 事项 | 说明 |
|---|---|
| 放哪 | `data/notes/week-XX/`，XX 是两位周号（01–36） |
| 标题 | 文件名（去掉 `.md`），不用在文件里写 title |
| 内容 | 随便写，纯 markdown 原样渲染 |
| 排序 | 按文件名排序；想按时间排，文件名加日期前缀：`2026-10-12-xxx.md` |

## 可选：文件开头写 frontmatter（不写也完全没问题）

```md
---
date: 2026-10-12
tags: [fastapi, pydantic]
---

正文……
```

写了 `date`/`tags`，笔记列表里就会显示日期和标签；不写就显示「未标日期」。

## 生效方式

- 本地 `pnpm dev`：保存文件后刷新页面即生效（Vite 会热更新）
- 线上链接：需要重新构建发布一次才会带上新笔记
