# 消息与提示词模版

## 一、Message

> 底层通用字段：
>
> role｜角色标识；
>
> content｜消息正文；
>
> metadata｜自定义元数据

### 1. 四大消息对象（对象格式）

- `SystemMessage`｜system 角色；设定 AI 角色、规则、行为约束
- `HumanMessage`｜user 角色；用户输入；支持 name 元数据区分多发言者
- `AIMessage`｜assistant 角色；大模型返回结果
  - `.tool_calls`｜列表，存储工具调用信息（工具名、参数、调用 id）
  - `.response_metadata`｜模型原始响应元信息，延迟、原始返回等
  - `.usage_metadata`｜标准化 token 用量（输入 / 输出 / 总 token）
  - `.additional_kwargs`｜附加字段，存拒答、推理思考内容等
- `ToolMessage`｜tool 角色；工具执行返回结果；**tool_call_id 必须匹配 AIMessage 工具调用 id**

> 配套格式：JSON 字典格式，和上面四类对象一一对应，用于对接原始 API

### 2. 消息内容两大属性

- `content`｜兼容老版本；支持字符串 / 字典列表（多模态老写法）
- `content_blocks`【LangChain1.2+】｜跨厂商标准化多模态结构，懒加载；支持 text/image/audio/reasoning；**优先读取拿思维链推理内容**

### 3. 业务逻辑：对话历史管理

1. 大模型服务端无记忆，**每次调用必须传入完整消息列表**
2. 新增交互：追加 HumanMessage；拿到模型结果追加 AIMessage
3. 历史膨胀优化：永久保留 system 消息，只保留 N 轮 user‑assistant 消息对

## 二、PromptTemplate

### 1. 基础模板类

- `PromptTemplate`｜老式模板；输出纯字符串；适合文本补全模型；不支持角色、不适合多轮对话
- `ChatPromptTemplate`【现代首选】｜聊天模板；输出消息列表；原生支持多角色、多轮对话

#### ChatPromptTemplate 实例化方式

1. `.from_messages()`【推荐静态方法】｜接收消息元素列表，构建模板
2. 直接构造`ChatPromptTemplate([...])`｜底层和 from_messages 等价

> from_messages 支持传入元素类型（可混合）
>
> - tuple 元组 `(role,模板字符串)`｜最常用
> - dict 字典｜json 消息字典
> - BaseMessage 实例（SystemMessage 等）⚠️不能写占位变量
> - XxxMessagePromptTemplate 消息模板对象（支持占位符）
> - BaseChatPromptTemplate｜嵌套子模板

#### ChatPromptTemplate 三种渲染调用方法

- `.invoke()`｜返回 ChatPromptValue 对象；直接传给模型 invoke
- `.format_messages()`｜返回`list[BaseMessage]`消息对象列表
- `.format()`｜返回纯字符串；仅调试打印，不要喂给 ChatModel

### 2. 细分消息模板

- `SystemMessagePromptTemplate`｜生成 SystemMessage 的模板
- `HumanMessagePromptTemplate`｜生成 HumanMessage 的模板
- `AIMessagePromptTemplate`｜生成 AIMessage 的模板

### 3. 高级组件

- `.partial()`｜模板实例方法；预填充部分固定变量，生成子模板
- `MessagesPlaceholder`｜消息占位符；在模板指定位置插入一整个消息列表；**用于注入对话历史、Agent 中间步骤**
- `+`运算符｜模板拼接；多个 ChatPromptTemplate 合并为一个

```python
"""
第 04 章 · 消息与提示词模板 —— 浓缩 demo

一章讲的东西，其实就 6 句话：
  1. 模型无状态 → messages 是"这一轮的完整输入"，不是聊天记录
  2. 四种角色：system 定规则 / human 用户 / ai 模型 / tool 工具结果
  3. 模板是"待填空"，invoke 是填空，不是调模型
  4. 真历史用 MessagesPlaceholder 注入，别手写假对话
  5. 管道 a | b | c 就是 c.invoke(b.invoke(a.invoke(x)))
  6. 工具调用靠 id 配对：模型喊单 → 你干活 → 带同一个 id 回执

跑法：
  pip install langchain-core langchain langchain-openai
  python w04_messages_prompt.py

前 4 段纯本地，不需要 API Key；后 2 段需要。
"""

from langchain_core.messages import SystemMessage, HumanMessage, AIMessage, ToolMessage
from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder


def title(n, text):
    print(f"\n{'=' * 12} PART {n} · {text} {'=' * 12}")


# ---------------------------------------------------------------- PART 1
title(1, "四种消息 = 对话里的四种角色")

msgs = [
    SystemMessage("你是前端面试官，回答不超过 30 字"),
    HumanMessage("什么是闭包"),
    AIMessage("闭包就是函数记住了它出生时的作用域。"),
    ToolMessage(content="查到了 3 条相关笔记", tool_call_id="call_abc123"),
]

for m in msgs:
    print(f"  {type(m).__name__:<14} | {m.content}")

print("\n  ↑ 这 4 条不是'聊天记录'，是你下一次要发给模型的完整输入")
print("  ↑ 模型不会记得上一轮，全靠你把历史重新贴一遍")


# ---------------------------------------------------------------- PART 2
title(2, "两种写法：dict 和对象")

as_dict = [
    {"role": "system", "content": "你是助手"},
    {"role": "user", "content": "你好"},
    {"role": "assistant", "content": "你好，有什么可以帮你"},
]

print("  dict 格式：")
for d in as_dict:
    print(f"    {d}")

print("\n  对象格式：")
for m in [SystemMessage("你是助手"), HumanMessage("你好"), AIMessage("你好，有什么可以帮你")]:
    print(f"    {type(m).__name__}")

print("\n  两者能力等价，但对象才有 .tool_calls / .id 这些属性")
print("  模型 API 只认 JSON 结构，LangChain 在发出去前帮你转换")


# ---------------------------------------------------------------- PART 3
title(3, "模板不是字符串，是待填空的纸")

template = ChatPromptTemplate.from_messages([
    ("system", "你是{role}，回答不超过{limit}字。"),
    ("human", "{question}"),
])

print(f"  类型：{type(template).__name__}（不是 str）")
print("  此刻里面还挂着 {role} {limit} {question} 三个空没填")

filled = template.invoke({
    "role": "前端面试官",
    "limit": 30,
    "question": "什么是闭包",
})

print("\n  invoke 之后（这一步是本地填空，没有网络请求）：")
for m in filled.to_messages():
    print(f"    {type(m).__name__:<14} | {m.content}")

print("\n  ↑ 填完出来的是 2 条消息，不是 1 段字符串")
print("  ↑ 少传一个变量会直接 KeyError，f-string 则会静默拼出 {question}")


# ---------------------------------------------------------------- PART 4
title(4, "真历史用 MessagesPlaceholder 注入，不是写死")

p = ChatPromptTemplate.from_messages([
    ("system", "你是天气助手，回答必须给：城市 + 温度区间 + 一句建议。"),
    MessagesPlaceholder("history"),
    ("human", "{user_input}"),
])

out = p.invoke({
    "history": [
        HumanMessage("上海今天冷吗"),
        AIMessage("上海多云，12–18℃，建议带件外套。"),
    ],
    "user_input": "那北京呢",
})

for m in out.to_messages():
    print(f"  {type(m).__name__:<14} | {m.content}")

print("\n  ↑ 用户问'那北京呢'，只有真历史在，模型才知道'那'指的是上海")
print("  ↑ 课件里手写的 '你好 / 我很好' 是假历史，生产代码基本不这么写")


# ---------------------------------------------------------------- PART 5
title(5, "管道 = 三次 invoke 串起来")

import os

if not os.getenv("OPENAI_API_KEY"):
    print("  跳过：未设置 OPENAI_API_KEY")
    print("  用 DeepSeek 的话：export DEEPSEEK_API_KEY=xxx，模型名换 deepseek:deepseek-chat")
else:
    from langchain.chat_models import init_chat_model
    from langchain_core.output_parsers import StrOutputParser

    model = init_chat_model("openai:gpt-4o-mini", temperature=0)
    parser = StrOutputParser()

    chain = template | model | parser
    print("  等价于：parser.invoke(model.invoke(template.invoke({...})))")
    print("  结果：", chain.invoke({"role": "前端面试官", "limit": 30, "question": "什么是闭包"}))


# ---------------------------------------------------------------- PART 6
title(6, "工具调用闭环：id 是单号，tool_call_id 是回执")

if not os.getenv("OPENAI_API_KEY"):
    print("  跳过：未设置 OPENAI_API_KEY")
else:
    from langchain.chat_models import init_chat_model
    from langchain_core.tools import tool

    @tool
    def get_weather(location: str) -> str:
        """查询指定城市今天的天气。用户问天气时必须调用。"""
        return f"{location}：今天天气很好"

    llm = init_chat_model("openai:gpt-4o-mini", temperature=0).bind_tools([get_weather])

    history = [HumanMessage("北京天气怎么样？")]
    ai = llm.invoke(history)
    print("  模型喊单：", ai.tool_calls)
    # [{'name': 'get_weather', 'args': {'location': '北京'},
    #   'id': 'call_00_xxx', 'type': 'tool_call'}]

    history.append(ai)  # ← 关键：AI 这条也要存回历史，否则后面挂不上
    for call in ai.tool_calls:
        history.append(
            ToolMessage(
                content=get_weather.invoke(call["args"]),
                tool_call_id=call["id"],  # ← 单号原样奉还，错一个字符就 400
            )
        )

    print("  最终回答：", llm.invoke(history).content)
    print("\n  ↑ 最后一次发出去的是 3 条：human + ai(喊单) + tool(回执)")
    print("  ↑ 中间不许插别的消息，否则报 'must be followed by tool messages'")


print(f"\n{'=' * 50}")
print("记住这一句：messages 是输入，不是记录。")
print(f"{'=' * 50}\n")

```
