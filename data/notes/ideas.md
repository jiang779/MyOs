## 2026-10-08 · 「一句报错」搜索引擎

tags: #产品 #Agent

把 Vue / React / Node 的高频报错做成一个可搜索的页面，每条报错配：人话解释 + 最可能的三个原因 + 修复代码。

价值不在搜索，在于每条结果都是人工审过的，没有废话。

和 Vue 报错 Agent 是同一份数据，一个做交互式、一个做静态 SEO 页。

## 2026-10-06 · 学习进度「温度计」

tags: #产品 #可视化

不是热力图（热力图只记录「有没有做」），而是记录「这周学到的东西有多难」。

输入方式：每天给自己今天的任务标一个 1–5 的难度，周末看曲线。连续几周都是 1–2 说明在舒适区。

## 2026-10-03 · 视频脚本的「三版钩子」生成器

tags: #创作 #工具

打开视频最大的阻力是第一句话。输入一个技术点，出三个不同风格的开头：反常识型 / 痛点型 / 结果型。

先做这个最小功能，比做完整脚本生成器更容易验证有没有用。

## 2026-09-30 · 把踩坑本做成周报

tags: #创作 #自动化

每周自动把 `data/notes/bugs.md` 里的新条目汇总成一条视频选题，格式：本周踩了 N 个坑，最值得讲的是这个。

现成的素材，几乎零额外成本。

## 2026-09-26 · 「我不确定」按钮

tags: #产品 #Agent

给 AI 助手加一个用户可点的「我不确定」按钮，用户点一次，就把这一轮对话标记为「模型判断失误」样本。

本质是在收集负样本，比人工整理评测集轻松得多。

## 2026-09-23 · 26 周计划表开源

tags: #创作 #开源

把这套 26 周 Agent 学习计划单独抽成一个模板仓库：每周期望交付物、推荐资料、常见卡点。

真正稀缺的不是知识，是「第 12 周该交什么」这种具体到吓人的安排。
