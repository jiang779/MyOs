## 0. 先读这一页

### 这份文档怎么用

- **不要一次读完。** 按第 14 节的 7 天路线，每天学 1–2 节。
- 每节结构固定：**是什么 → 怎么用 → 背后一句话 → 自测**。
- 边看边打开项目点一遍，比只看文字快。
- 术语第一次出现会用大白话解释；完整名词表在第 12 节。

### 三条学习原则

1. **先会用，再懂原理。** 不会用的时候，原理只会增加负担。
2. **用“输入 → 处理 → 输出”理解每个功能。** 不需要看代码。
3. **每学完一块，能用自己的话讲 1 分钟**，才算真的会。

### 三分钟总览

现在的 AI 助手能做的事：

- 聊天，回答一个字一个字出现，可随时停止
- 回答里区分「正文 / 思考过程 / 工具调用 / 引用」
- 多个会话，能新建、切换、重命名、删除，刷新还在
- 知识库：上传 txt / md / pdf / docx，绑定后回答带引用
- 设置：选模型、调温度、限制最大 token、绑定知识库
- 工具：注册 MCP 服务、同步工具、启用停用、按会话勾选
- 工具调用/结果会显示成卡片，失败可重试

现在的边界（很重要）：

- **工具真正“执行”需要后端**。没有后端时，直连模式不会真的调用 MCP 工具；mock 模式只是演示卡片。
- **断线续传只在 http / mock 模式生效**；直连模式刷新后会把未完成回答标记为「已停止」。
- 知识库、会话、工具配置都存在**浏览器本地**，换设备/换端口不会自动同步。

### 功能地图

```
右下角粒子球
   │ 点击
   ▼
对话面板
   ├── 消息区
   │     ├── 正文
   │     ├── 思考过程（可折叠，显示耗时）
   │     ├── 工具调用卡片（参数 / 结果 / 耗时 / 重试）
   │     └── 引用列表（标题 / 摘要 / 相似度 / 展开原文）
   ├── 输入框（Enter 发送 / Shift+Enter 换行 / 停止）
   ├── 会话（新建 / 切换 / 重命名 / 删除）
   └── 设置（模型 / 温度 / 最大 token / 知识库 / 工具入口）
           │
           ├── 知识库页（建库 / 上传 / 绑定）
           └── 工具页（MCP 服务 / 同步 / 启用停用 / 会话勾选）
```

## 1. 认识助手：右下角的粒子球

### 是什么

页面右下角有一团会动的粒子：

- 平时是一个致密的圆球
- 鼠标移上去会膨胀成不规则团簇
- 点一下打开对话面板，再点一下（或点面板右上角 ×）关闭

它不是一个普通按钮，而是这个 AI 助手的**唯一入口**。

### 怎么用

1. 找到右下角粒子球。
2. 点一下，面板从右侧出现。
3. 面板右上角四个图标，从左到右：
   - **设置**（滑杆）：模型、温度、token、知识库、工具
   - **会话列表**：切换/重命名/删除会话
   - **新建会话**：开一个干净的上下文
   - **关闭**
4. 点面板外的页面不会自动关闭；用 × 或 Esc 关闭。

### 背后一句话

粒子球是一个用 Canvas 画的动画按钮；打开面板只是切换一个界面状态，不涉及 AI 请求。

### 自测

- 粒子球在哪个位置？打开和关闭各有哪几种方式？
- 面板右上角四个图标分别做什么？
- 关闭面板后，刚才的对话会丢吗？（不会，存在本地）

## 2. 第一次对话

### 是什么

在输入框里说一句话，助手回你一段话。回答不是“等全部生成完再出现”，而是**一个字一个字流出来**。

### 怎么用

1. 打开面板，输入框默认聚焦。
2. 输入问题。
3. **Enter 发送**；**Shift + Enter 换行**。
4. 回答过程中，发送按钮会变成方块，点它可以**停止**。
5. 停止后，已经收到的内容会保留，消息标记「已停止」。
6. 回答很长时，**往上滑会暂停自动跟随**；面板右下角会出现一个 ↓ 按钮，点它回到底部。

空状态（还没有消息）会显示：

- 一句开场白
- 3 条预设问题，点一下直接发送

### 背后一句话

你的问题发给模型后，模型不是一次性算完，而是像水龙头一样一点点送回来；界面接到一点就显示一点，所以看起来像在“打字”。

### 常见情况

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 发不出去 | 模型配置缺失 / 网络断开 | 检查设置和网络；刷新再试 |
| 一直没有回答 | 模型慢 / 网络卡 | 点停止；新建会话再试 |
| 回答突然停 | 网络断 / 手动停止 | 看消息底部标签；必要时重发 |
| 中文输入法回车误发送 | 输入法还在选词 | 选完词再按 Enter |

### 自测

- Enter 和 Shift+Enter 分别做什么？
- 回答到一半点停止，已收到的内容会保留吗？
- 空状态的 3 条预设问题在哪里？

## 3. 看懂一条回答

### 是什么

一条助手回答可能由四种内容组成，不是只有一段文字：

| 内容 | 长什么样 | 作用 |
|---|---|---|
| **正文** | 普通文字、列表、代码块、表格 | 最终答案 |
| **思考过程** | 可折叠的「思考过程 · 320ms」 | 模型的草稿纸，帮你判断它怎么想的 |
| **工具调用** | 一张卡片：工具名、参数、结果、耗时 | 记录模型调用了什么外部能力 |
| **引用** | 回答底部的「引用 1/2/3」 | 答案参考了哪些资料 |

### 怎么用

- **思考过程**：点标题展开/收起；标题右侧是耗时。完成后的回答默认收起。
- **工具卡片**：
  - 「参数」可展开，看模型传了什么
  - 「结果」可展开，看工具返回了什么
  - 失败时显示「工具执行失败」和「重试」
- **引用**：
  - 列表显示标题、摘要、相似度
  - 点一条展开原文片段
- **状态标签**：消息底部可能出现「已停止」「出错」。

### 背后一句话

模型在流式返回时，会同时送三种“段落”：思考、工具调用、正文；界面按类型分别渲染，不是把一坨文字硬拆。

### 自测

- 思考过程的耗时是从什么时候算到什么时候？
- 工具卡片的参数和结果分别在哪里展开？
- 引用列表里的百分比代表什么？（检索匹配度，不是答案正确率）

## 4. 会话管理

### 是什么

每个会话是一个独立的聊天室：

- 有自己的消息
- 有自己的上下文（模型只看得到这个会话里的内容）
- 有自己的标题

### 怎么用

1. 面板右上角 **＋**：新建会话。
2. 面板右上角 **列表图标**：打开会话列表。
3. 在列表里：
   - 点会话名：切换
   - 铅笔图标：重命名
   - 垃圾桶：删除（点两次确认）
4. 刷新页面后，会话和消息还在。

### 背后一句话

会话的“目录信息”（标题、时间、消息数）存在浏览器的小记事本里；消息正文存在浏览器的大抽屉里。刷新不会丢，但清站点数据会丢。

### 常见情况

- **换会话后模型不记得上一个会话**：正常，每个会话独立。
- **想聊新话题但不想丢旧记录**：新建会话，不要删旧的。
- **删除会话**：消息一起删除，不能撤销。

### 自测

- 新建、切换、重命名、删除分别在哪里？
- 刷新后消息还在吗？为什么？
- 为什么换会话后模型不记得上一个会话？

## 5. 知识库：让助手“开卷考试”

### 是什么

知识库就是你给助手准备的一书架资料。

- 不绑定知识库：助手靠自己的通用知识回答
- 绑定知识库：助手先从你的资料里找相关片段，再回答，并在末尾附上引用

### 怎么用（完整流程）

1. 顶部导航点 **知识库**（移动端可从助手设置里的「管理知识库」进入）。
2. 左侧输入名称，点 **新建**。
3. 右侧点 **上传文档**，或把文件拖进右侧区域。
   - 支持 `txt / md / pdf / docx`
   - 单文件 ≤ 10MB
   - 可一次选多个
4. 等文档出现在列表里，显示「X 个片段」就表示解析成功。
5. 在左侧知识库卡片上勾选 **绑定**。
   - 勾选 = 这个库参与回答
   - 可以同时勾多个库
   - **不勾选就不会被使用**
6. 打开助手，提问。回答底部会出现「引用」。
7. 点引用标题，展开原文片段。

### 背后一句话

上传时，系统把文档拆成一段段小卡片（叫“片段”）；提问时，先找最相关的几张卡片，连同问题一起交给模型——就像开卷考试先翻到相关那几页。

### 哪些文件可能解析不好

- **扫描版 PDF**（整页是图片，没有文字层）：可能提取不到文字。
- **加密 PDF**：可能打不开。
- **超大文档**：会截断到一定片段数，建议拆分上传。
- **老式 `.doc`**：不支持，请另存为 `.docx`。

### 数据存在哪

存在**当前浏览器本地**，不上传整份文件。

- 刷新、重启浏览器还在
- 换浏览器、换设备、换端口、清站点数据会没
- 重要资料请保留原文件

### 自测

- 上传成功后，怎么判断解析成功？（看片段数 > 0）
- 绑定勾选在哪？不勾选会怎样？
- 为什么扫描版 PDF 可能没有内容？
- 换一台电脑，知识库还在吗？

## 6. 引用与可信度

### 是什么

引用是回答后面的“参考资料列表”，告诉你：

- 用了哪份文档（标题）
- 这段大概讲了什么（摘要）
- 和问题有多匹配（相似度）

### 怎么用

1. 看回答底部「引用 N」。
2. 每条显示：序号、标题、摘要、相似度。
3. 点标题展开原文片段。
4. 对照原文判断回答是否可信。

### 三个常见误解

| 误解 | 实际情况 |
|---|---|
| 相似度越高，答案越对 | 相似度只是“这段资料和问题有多匹配”，不是答案正确率 |
| 没有引用 = 回答错 | 可能只是没绑定知识库，或问题不需要资料 |
| 引用多 = 质量高 | 可能只是检索到很多相似片段，仍要自己判断 |

### 没有引用怎么办

按顺序检查：

1. 知识库卡片上的 **绑定** 有没有勾？
2. 问题是否和资料内容相关？
3. 文档片段数是否 > 0？
4. 设置里知识库是否勾选？

### 隐私

- 资料在浏览器本地解析、本地存储
- 提问且绑定知识库时，命中的**片段**会作为上下文发给模型服务
- 不会整份上传文件
- 如果以后接后端，服务端会有自己的知识库存储

### 自测

- 引用列表的三列分别是什么？
- 相似度 17% 代表回答不可信吗？
- 没有引用时，先检查哪三件事？

## 7. 设置：把助手调成你要的样子

### 是什么

助手头部的 **滑杆图标** 打开设置，包含：

- 模型
- 温度
- 最大 token
- 知识库绑定
- 工具入口

### 每项是什么意思

| 设置 | 大白话 | 建议 |
|---|---|---|
| **模型** | 请哪位老师来回答 | 默认用 `.env` 里的模型；不确定就别改 |
| **温度** | 创意程度 | 0.3–0.7 稳重；1.0 左右更发散；不要一上来拉满 |
| **最大 token** | 最多说多少字 | 2048 日常够用；长文/代码可调到 4096 |
| **知识库** | 允许翻哪些书 | 只勾当前需要的，避免串味 |
| **工具** | 允许用哪些工具 | 在工具页按会话勾选 |

### 怎么用

1. 打开设置。
2. 改完自动保存，不需要点“保存”。
3. **下一条消息生效**。
4. 点左上角返回箭头回到对话。

### 背后一句话

设置存在浏览器本地，发请求时作为参数带上；模型/温度/token 影响模型怎么答，知识库/工具影响它能“看到什么、用什么”。

### 自测

- 改完设置，当前正在生成的回答会变吗？（不会，下一条生效）
- 温度和 token 分别控制什么？
- 知识库多选在哪里？

## 8. 工具（MCP）：给助手装插件

### 是什么

MCP 可以理解为“给 AI 用的插件标准”。

- **MCP 服务**：一个工具箱，比如“本地工具”“搜索服务”
- **工具**：工具箱里的具体工具，比如 `echo_text`、`search_notes`、`read_url`
- **工具卡片**：模型调用工具后，界面上的使用记录

### 三层开关，别搞混

| 层级 | 在哪 | 含义 |
|---|---|---|
| 服务启用 | 工具页左侧 | 这个工具箱整体可用 |
| 工具启用 | 工具页右侧 | 这个工具在注册表里可用 |
| 当前会话勾选 | 工具页上方 | 这次对话允许模型用哪些工具 |

### 三种 transport（送货方式）

| transport | 大白话 | 适合 |
|---|---|---|
| HTTP | 快递：发一个请求，拿一份工具清单 | 有 HTTP MCP 服务 |
| SSE | 实时通话：先连上，再一问一答 | 标准 MCP SSE 服务 |
| Command | 本地跑腿：在电脑上起一个进程 | 本地 MCP server |

### 怎么用（本地 demo）

1. 终端运行 `node scripts/mcp-bridge.mjs`（command 需要它）。
2. 工具页新增服务：
   - 名称：本地 MCP
   - transport：Command
   - 命令：`node scripts/mock-mcp-server.mjs`
3. 点「同步工具」，右侧出现 3 个工具。
4. 勾选当前会话要用的工具（比如回显文本）。
5. 打开助手提问；会看到工具卡片。

HTTP / SSE 可以填 bridge 的 mock 地址：

- HTTP：`http://127.0.0.1:5198/mcp/http`
- SSE：`http://127.0.0.1:5198/mcp/sse`

### 现在能做什么、不能做什么

**已经完成：**

- 注册 MCP 服务
- 同步工具列表
- 启用/停用服务、工具
- 按会话勾选要暴露的工具
- 发起对话时提交工具 id
- 工具调用/结果渲染成卡片，失败可重试

**还没完成：**

- **工具的真正执行**。直连模式没有执行器；mock 只是演示卡片；http 模式需要后端接收 `toolIds` 并执行 MCP 工具。
- 所以：现在能“把工具准备好、把选择提交上去、把结果卡片渲染出来”，但“模型真的调用工具并拿结果继续回答”需要后端闭环。

### command 的安全提醒

`scripts/mcp-bridge.mjs` 会在本机执行前端传来的命令：

- 只在本机开发用
- 不要暴露到公网
- 不要填来源不明的命令

### 自测

- 服务、工具、当前会话勾选三层分别是什么意思？
- 为什么 command 需要 bridge？
- 工具卡片出现了，就代表工具真的执行了吗？（不一定，看模式）

## 9. 断线与续传

### 是什么

回答到一半网络断了，重新连上后**接着收**，已经收到的内容不重复。

### 怎么用

- 页面刷新后，如果还有未完成请求，助手会尝试自动续传。
- 网络恢复时也会自动尝试。
- 失败时，面板会出现「连接中断，已收内容已保留」和「继续接收」按钮。
- 已收内容会保留，不会清空。

### 重要限制

| 模式 | 续传 |
|---|---|
| 直连（浏览器直接连模型） | **不支持**；刷新后标记「已停止」 |
| http（经过后端） | 支持（需要后端实现 `/api/chat/receive`） |
| mock（演示） | 支持 |

原因：续传需要服务端把流“录下来”；直连模式没有这个录像机。

### 背后一句话

服务端给每一路回答一个“快递单号”；断线后凭单号继续取，客户端按单号跳过已经取过的部分。

### 自测

- 直连模式刷新后，未完成的回答会怎样？
- 什么模式下续传才生效？
- 「继续接收」按钮在什么情况下出现？

## 10. 数据存在哪、会不会丢

### 两类“抽屉”

| 抽屉 | 存什么 | 特点 |
|---|---|---|
| **小记事本**（localStorage） | 会话目录、设置、工具选择、续传单号 | 容量小，读写快 |
| **大抽屉**（IndexedDB） | 消息正文、知识库片段、MCP 工具 | 容量大，适合大文本 |

### 什么时候还在

- 刷新页面：在
- 关闭浏览器再打开：在
- 重启电脑：在
- 同一个浏览器、同一个地址/端口、同一个用户配置：在

### 什么时候会丢

- 换端口：`localhost:5199` 和 `localhost:5200` 是**两个不同的房子**
- 换域名、换浏览器、换设备：各存各的
- 无痕模式：关窗口就没
- 清除站点数据：会清
- 浏览器存储空间紧张：可能被回收
- IndexedDB 不可用：退化为内存，刷新即丢

### 怎么确认

浏览器 F12 → Application：

- Local Storage：`myos.ai.*`
- IndexedDB：`myos-kb`、`myos-mcp`、`myos-ai`

### 备份建议

- 目前**没有导出/导入**功能
- 重要资料保留原文件
- 重要对话可以手动复制

## 11. 常见问题排查

| 现象 | 先检查 | 处理 |
|---|---|---|
| 右下角没有粒子球 | 页面是否加载完成 | 刷新；看控制台是否有报错 |
| 面板打不开 | 是否点到了球 | 再点一次；按 Esc 后重试 |
| 消息发不出去 | 模型配置 / 网络 | 检查 `.env.local` 和网络；刷新 |
| 回答一直不出字 | 网络 / 模型慢 | 点停止；新建会话再试 |
| 回答没有引用 | 知识库是否绑定 | 勾选绑定；确认片段数 > 0 |
| 引用相似度很低 | 问题与资料不匹配 | 换问法；补充资料 |
| 工具列表为空 | 是否同步过 | 点同步；检查服务返回 |
| 同步失败（command） | bridge 是否启动 | 运行 `node scripts/mcp-bridge.mjs` |
| 同步失败（http/sse） | endpoint 是否正确 | 检查地址、跨域、服务日志 |
| 勾选了工具但没卡片 | 是否直连模式 | 直连不执行工具；切 http/mock |
| 工具卡片失败 | 工具参数/下游服务 | 展开参数和结果；点重试 |
| 刷新后消息没了 | 是否换了端口/浏览器 | 换回原地址；检查是否清过数据 |
| 知识库上传失败 | 格式/大小/扫描件 | 换格式；压缩到 10MB 内；扫描件需 OCR |
| 改设置没生效 | 是否已发下一条 | 设置只影响后续请求 |
| 换会话后工具选择变了 | 选择按会话存 | 正常；切回原会话会恢复 |
| 回答很长时往上滑被拉回底部 | 旧版本的滚动回环 | 已修复；上滑会暂停自动跟随，点右下角 ↓ 回到底部 |

## 12. 名词表

| 名词 | 大白话 |
|---|---|
| **模型** | 负责回答的 AI 大脑 |
| **Token** | 模型读写文字的单位，也是计费单位 |
| **温度** | 回答的创意程度，低稳重、高发散 |
| **流式 / SSE** | 回答像水龙头一样一点点送回来，不是等全部生成完 |
| **chunk** | 流式传输中的一小片数据 |
| **Markdown** | 用符号排版的文本，比如 `#` 标题、`-` 列表 |
| **RAG** | 先检索资料再回答，即“开卷考试” |
| **片段 / chunking** | 把长文档拆成小段，方便检索 |
| **引用 / Reference** | 回答参考了哪些资料 |
| **相似度** | 资料和问题的匹配程度，不是答案正确率 |
| **MCP** | 给 AI 用的插件标准 |
| **transport** | 工具服务的连接方式：HTTP / SSE / Command |
| **bridge** | 本地小桥，帮浏览器执行 command |
| **IndexedDB** | 浏览器里的大抽屉，存大文本 |
| **localStorage** | 浏览器里的小记事本，存设置等小数据 |
| **直连模式** | 浏览器直接连模型 |
| **http 模式** | 浏览器经过自己的后端再连模型 |
| **mock 模式** | 演示模式，不消耗额度，用假数据跑流程 |
| **续传** | 断线后接着收，已收内容不重复 |
| **seq** | 流式事件的“快递单号”，用来去重 |

## 14. 7 天学习路线

| 天 | 目标 | 动手 | 自测 |
|---|---|---|---|
| Day 1 | 会打开、会发消息、会停止 | 点球 → 问一个问题 → 中途停止 | 能说出 Enter / Shift+Enter / 停止 |
| Day 2 | 看懂三类块 + 会话 | 展开思考、展开工具卡、新建/切换/重命名 | 能解释正文/思考/工具/引用的区别 |
| Day 3 | 知识库跑通 | 建库 → 上传 md/pdf → 绑定 → 提问 → 看引用 | 能说出上传→切块→绑定→检索→引用 |
| Day 4 | 设置调优 | 改温度/token，观察回答变化 | 能说出温度/token 的影响 |
| Day 5 | 工具跑通 | 起 bridge → 加 command 服务 → 同步 → 勾选 → 提问 | 能说出服务/工具/会话勾选三层 |
| Day 6 | 数据与排错 | 刷新、换会话、看 F12 存储 | 能说出什么会丢、什么不会 |
| Day 7 | 讲清楚 | 不看文档画功能地图，讲 5 分钟 | 能回答第 15 节的 8 个问题 |

**Day 8+（进阶）：** 接后端，让工具真正执行；把知识库迁到服务端；补部署、鉴权、评测。
